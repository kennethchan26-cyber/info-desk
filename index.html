Gmail OAuth 設定摘要
  1. Google Cloud 建立項目並啟用 Gmail API。
  2. OAuth 同意畫面加入自己為測試使用者及 gmail.readonly。
  3. 網頁版 Web Client 加入 GitHub Pages 的 origin 為 JavaScript 來源；保留原有來源。
  4. 擴充功能的 Web Client 保留畫面所示 Redirect URI。兩種模式可使用同一個 Web Client。
  5. 在 config.js 填入公開 Client ID，不放任何密碼或 Client Secret。

iPhone：用 Safari 開啟 → 分享 → 加入主畫面。登入須在各瀏覽器分別授權。

網頁保持開啟才會更新及提示；手機背景、鎖屏或關頁後不保證更新，沒有背景推播。
